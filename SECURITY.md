# Security Policy

## Supported versions

Security fixes are made to the latest release on [PyPI](https://pypi.org/project/scikit-bayes/) only. Please check that a problem still occurs with the latest release before reporting it.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Report them privately by e-mail to the maintainer, Pablo Torrijos, at <pablo.torrijos@uclm.es>.

Include the version of scikit-bayes, a description of the problem and, if possible, a minimal example that reproduces it. The fix will be announced in the release notes once it is published.
