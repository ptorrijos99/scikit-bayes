WeightedNB#

class skbn.WeightedNB(categorical_features=None, bernoulli_features=None, gaussian_features=None, var_smoothing=1e-09, alpha=1.0, var_prior_weight=0.0, weight_level=3, l2_reg=1.0, max_iter=1000, tol=1e-06)#

Weighted Mixed Naive Bayes classifier (WANBIA / wCCBN on Naive Bayes).

Extends MixedNB with discriminative exponent weights on the class prior and every attribute conditional, learned by maximising the conditional log-likelihood with L-BFGS-B:

\[\log P^w(y \mid \mathbf{x}) = w_y \log P(y) + \sum_{i} w_{i, x_i, y} \log P(x_i \mid y) - \log Z(\mathbf{x}).\]

The objective is convex. The weights start at, and are regularized towards (l2_reg), the generative model w = 1, which predicts as MixedNB. weight_level=1 gives one weight per factor (WANBIA-C [1]), weight_level=2 one weight per factor and discrete value, and weight_level=3 (default) one weight per factor, discrete value and class (the weighted CCBN of Zaidi et al. [2] on the Naive Bayes structure).

Parameters:
categorical_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the features to treat as categorical.

bernoulli_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the features to treat as Bernoulli.

gaussian_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the features to treat as Gaussian.

var_smoothingfloat, default=1e-9

Non-negative portion of the largest variance of all Gaussian features added to variances for calculation stability.

alphafloat, default=1.0

Non-negative additive (Laplace/Lidstone) smoothing parameter.

var_prior_weightfloat, default=0.0

Non-negative number of pseudo-observations shrinking each Gaussian variance towards the pooled variance of the feature.

weight_levelint, default=3

Granularity of the weights, from 1 (one weight per factor: WANBIA-C) to 3 (one weight per factor, discrete value and class).

l2_regfloat, default=1.0

Non-negative L2 regularization towards the generative solution (w = 1), added to the summed conditional log-likelihood.

max_iterint, default=1000

Maximum number of L-BFGS-B iterations (at least 1).

tolfloat or None, default=1e-6

Stopping tolerance of L-BFGS-B on the relative reduction of the objective and on the projected gradient.

Attributes:

class_log_prior_ndarray of shape (n_classes,)

Log of the empirical frequency of each class.

n_features_in_int

Number of features seen during fit.

feature_names_in_ndarray of shape (n_features_in_,)

Names of features seen during fit. Defined only when X has feature names that are all strings.

feature_types_dict

categories_list of ndarray

Sorted training values of each categorical feature.

bernoulli_thresholds_ndarray of shape (n_bernoulli_features,)

Binarisation threshold of each Bernoulli feature.

learned_weights_ndarray of shape (n_weights,)

Learned weights w.

Number of weights, including the shared one for unseen combinations.

Weights of the class prior: one per class at weight_level=3, a single one below.

feature_weights_list of ndarray

Weights of the conditional of every attribute, a list with one array per attribute.

n_iter_int

Number of L-BFGS-B iterations.

References

[1]

Zaidi, N. A., Cerquides, J., Carman, M. J., & Webb, G. I. (2013). Alleviating naive Bayes attribute independence assumption by attribute weighting. Journal of Machine Learning Research, 14, 1947-1988.

[2]

Zaidi, N. A., Webb, G. I., Carman, M. J., Petitjean, F., Buntine, W., Hynes, M., & De Sterck, H. (2017). Efficient parameter learning of Bayesian network classifiers. Machine Learning, 106(9-10), 1289-1329.

Examples

>>> import numpy as np
>>> from sklearn.metrics import log_loss
>>> from skbn import MixedNB, WeightedNB
>>> rng = np.random.RandomState(0)
>>> y = rng.randint(0, 2, size=300)
>>> x = rng.normal(size=300) + y
>>> X = np.column_stack([x, x, x, rng.normal(size=300) + y])
>>> clf = WeightedNB(weight_level=1).fit(X, y)
>>> nb = MixedNB().fit(X, y)
>>> bool(log_loss(y, clf.predict_proba(X)) < log_loss(y, nb.predict_proba(X)))
True

set_fit_request(*, sample_weight: bool | None | str = '$UNCHANGED$') → WeightedNB#

Configure whether metadata should be requested to be passed to the fit method.

Note that this method is only relevant when this estimator is used as a sub-estimator within a meta-estimator and metadata routing is enabled with enable_metadata_routing=True (see sklearn.set_config()). Please check the User Guide on how the routing mechanism works.

The options for each parameter are:

  • True: metadata is requested, and passed to fit if provided. The request is ignored if metadata is not provided.

  • False: metadata is not requested and the meta-estimator will not pass it to fit.

  • None: metadata is not requested, and the meta-estimator will raise an error if the user provides it.

  • str: metadata should be passed to the meta-estimator with this given alias instead of the original name.

The default (sklearn.utils.metadata_routing.UNCHANGED) retains the existing request. This allows you to change the request for some parameters and not others.

Added in version 1.3.

Parameters:
