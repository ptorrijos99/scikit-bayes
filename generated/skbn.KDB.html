KDB#

class skbn.KDB(k=1, n_bins=5, strategy='quantile', alpha=1.0, categorical_features=None, bernoulli_features=None, gaussian_features=None, var_prior_weight=1.0, n_jobs=None)#

K-Dependence Bayesian (KDB) classifier.

KDB [1] extends Naive Bayes with dependencies between the attributes: each attribute has the class and at most k other attributes as parents.

\[P(y, \mathbf{x}) = P(y) \prod_{i} P(x_i \mid y, \mathbf{x}_{\Pi(i)}), \qquad |\Pi(i)| \leq k\]

where \(\Pi(i)\) is the set of attribute parents of attribute \(i\). With k=0 the model is Naive Bayes.

Structure. The attributes are sorted by decreasing empirical mutual information with the class \(I(A_i; C)\) and added to the network in that order. Each attribute takes as parents the \(\min(k, t)\) attributes, among the \(t\) already added, with the highest empirical conditional mutual information \(I(A_i; A_j \mid C)\). Continuous attributes are discretized (n_bins, strategy) to compute these quantities.

Parameters. Every conditional \(P(x_i \mid y, \mathbf{x}_{\Pi(i)})\) with at least one attribute parent is estimated as Naive Bayes on the augmented class \(Y^* = (y, \mathbf{x}_{\Pi(i)})\), the strategy used by the AnDE family and TAN: discrete children use Laplace smoothing with alpha, continuous children are Gaussian (shrunk towards the pooled variance with var_prior_weight), and continuous parents are discretized. When a test instance falls in a state \((y, \mathbf{x}_{\Pi(i)})\) never observed in training, the child conditional is the uninformed estimate that Laplace smoothing gives an empty cell: uniform for discrete children, the pooled Gaussian of the attribute for continuous ones. The class prior and the conditionals of the attributes without attribute parents are those of a MixedNB fitted on the original class.

Parameters:
kint, default=1

Maximum number of attribute parents of every attribute, in addition to the class. An attribute placed when fewer than k attributes are in the network takes all of them as parents. k=0 gives Naive Bayes. fit() raises a ValueError when the joint states of the class and the parents of an attribute exceed a 64-bit index, which calls for a smaller k or fewer bins.

n_binsint, default=5

Number of bins used to discretize continuous attributes for the structure learning and when they act as parents. Continuous children remain continuous.

strategy{‘uniform’, ‘quantile’, ‘kmeans’}, default=’quantile’

Strategy used for the discretization of continuous attributes.

alphafloat, default=1.0

Non-negative additive (Laplace/Lidstone) smoothing parameter for the discrete conditional probability tables.

categorical_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the features to treat as categorical, passed to MixedNB, which describes how the undeclared features are typed.

bernoulli_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the features to treat as Bernoulli. See MixedNB.

gaussian_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the features to treat as Gaussian. See MixedNB.

var_prior_weightfloat, default=1.0

Non-negative number of pseudo-observations shrinking each Gaussian variance towards the pooled variance of the feature (see MixedNB).

n_jobsint, default=None

Number of threads used to compute the conditional mutual information and to count and evaluate the conditionals. None means 1 and -1 all the processors.

Attributes:
classes_ndarray of shape (n_classes,)

Class labels known to the classifier.

n_features_in_int

Number of features seen during fit.

feature_names_in_ndarray of shape (n_features_in_,)

Names of features seen during fit. Defined only when X has feature names that are all strings.

mutual_info_ndarray of shape (n_features,)

Empirical mutual information \(I(A_i; C)\) (in nats) between every (discretized) attribute and the class.

conditional_mutual_info_ndarray of shape (n_features, n_features)

Empirical conditional mutual information \(I(A_i; A_j \mid C)\) (in nats) between every pair of (discretized) attributes.

feature_order_ndarray of shape (n_features,)

Attributes in the order in which they were added to the network (decreasing mutual_info_).

parents_list of ndarray

parents_[i] holds the attribute parents of attribute i, by decreasing conditional_mutual_info_; it is empty for the attributes that depend only on the class.

backoff_MixedNB

Naive Bayes on the original class. Provides the class prior, the conditionals of the attributes without attribute parents and the detected feature types (feature_types_).

Examples

>>> import numpy as np
>>> from skbn import KDB
>>> rng = np.random.RandomState(0)
>>> x0 = rng.randint(0, 2, size=200)
>>> x1 = rng.randint(0, 2, size=200)
>>> x2 = rng.randint(0, 2, size=200)
>>> y = x0 ^ x1 ^ x2  # parity: no pair of attributes is informative
>>> X = np.column_stack([x0, x1, x2])
>>> clf = KDB(k=2).fit(X, y)
>>> [p.tolist() for p in clf.parents_]
[[], [0], [0, 1]]
>>> clf.score(X, y)
1.0
>>> KDB(k=1).fit(X, y).score(X, y) < 0.7
True

set_score_request(*, sample_weight: bool | None | str = '$UNCHANGED$') → KDB#

Configure whether metadata should be requested to be passed to the score method.

Note that this method is only relevant when this estimator is used as a sub-estimator within a meta-estimator and metadata routing is enabled with enable_metadata_routing=True (see sklearn.set_config()). Please check the User Guide on how the routing mechanism works.

The options for each parameter are:

  • True: metadata is requested, and passed to score if provided. The request is ignored if metadata is not provided.

  • False: metadata is not requested and the meta-estimator will not pass it to score.

  • None: metadata is not requested, and the meta-estimator will raise an error if the user provides it.

  • str: metadata should be passed to the meta-estimator with this given alias instead of the original name.

The default (sklearn.utils.metadata_routing.UNCHANGED) retains the existing request. This allows you to change the request for some parameters and not others.

Added in version 1.3.

Parameters:
