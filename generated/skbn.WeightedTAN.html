WeightedTAN#

class skbn.WeightedTAN(root=0, n_bins=5, strategy='quantile', alpha=1.0, categorical_features=None, bernoulli_features=None, gaussian_features=None, var_prior_weight=1.0, n_jobs=None, weight_level=4, l2_reg=1.0, max_iter=1000, tol=1e-06, continuous_children='gaussian')#

Discriminatively weighted Tree Augmented Naive Bayes.

The weighted conditionally Bayesian network (wCCBN) of Zaidi et al. [1] on the structure and the conditionals of TAN [2]: every parameter of the network gets an exponent weight,

\[P^w(y \mid \mathbf{x}) \propto P(y)^{w_y} \, P(x_r \mid y)^{w_{r, x_r, y}} \prod_{i \neq r} P(x_i \mid y, x_{\pi(i)})^{w_{i, x_i, y, x_{\pi(i)}}},\]

and the weights maximise the conditional log-likelihood of the training set, penalized by l2_reg * ||w - 1||^2, with L-BFGS-B and analytic gradients. The structure and the probabilities are those of TAN and stay fixed: the weights start at, and are regularized towards, the generative model (w = 1). The objective is convex in the weights.

The weights correct what the generative fit gets wrong when the data break the independence assumptions of the tree, for instance attributes that are correlated or duplicated beyond what one parent explains: they scale down the conditionals that count the same evidence twice.

Weight levels (variables indexing each weight, from coarsest to finest), the nested parameterizations of [1]:

Level

Variables

1

Factor

2

Factor x value

3

Factor x value x class

4

Factor x value x class x parents

A factor is the class prior \(P(y)\) or the conditional of an attribute; the class prior has a single value and no parents, so it gets one weight per class at levels 3 and 4. Level 4 (the default), one weight per parameter of the network, is the wCCBN of [1]: a reparameterization of the discriminative learning of the parameters of that network, which [1] found faster to optimize. The value of a Gaussian child is not discretized, so its weights ignore the “value” dimension. Only the combinations that occur in training get a weight; the others share one weight that keeps its generative value, so the number of weights is bounded by the data. This is WeightedAnDE with weight_scope="factor" and mean="geometric" applied to the single network of TAN. A test instance in a parent state never seen in training gets the uninformed conditional of TAN. The fit keeps the per-factor log-likelihoods of the training set in memory, about 12 * n_samples * n_classes * (n_features + 1) bytes, and each evaluation of the objective costs as much.

Parameters:
rootint, default=0

Index of the attribute used as root of the tree, in [0, n_features - 1]. The root does not change the edges of the tree, only their direction, but with smoothing (alpha > 0) the estimates, and so the predictions, depend on the direction.

n_binsint, default=5

Number of bins used to discretize continuous attributes for the structure learning and when they act as parents. Continuous children remain continuous.

strategy{‘uniform’, ‘quantile’, ‘kmeans’, ‘mdlp’}, default=’quantile’

Strategy used for the discretization of continuous attributes. 'mdlp' places the cuts with the supervised entropy discretization of Fayyad and Irani (see MDLPDiscretizer), which chooses the number of bins of each attribute, so n_bins is not used.

alphafloat, default=1.0

Non-negative additive (Laplace/Lidstone) smoothing parameter for the discrete conditional probability tables.

categorical_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the features to treat as categorical, passed to MixedNB, which describes how the undeclared features are typed.

bernoulli_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the features to treat as Bernoulli. See MixedNB.

gaussian_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the features to treat as Gaussian. See MixedNB.

var_prior_weightfloat, default=1.0

Non-negative number of pseudo-observations shrinking each Gaussian variance towards the pooled variance of the feature (see MixedNB).

n_jobsint, default=None

Number of threads used to compute the conditional mutual information and to count and evaluate the conditionals; the weights are optimized in a single thread. None means 1 and -1 all the processors.

weight_levelint, default=4

Granularity of the weights, from 1 (coarsest) to 4 (finest); see the table above.

l2_regfloat, default=1.0

Non-negative L2 regularization towards the generative solution (w = 1), added to the summed conditional log-likelihood.

max_iterint, default=1000

Maximum number of L-BFGS-B iterations (at least 1). A ConvergenceWarning is raised at the end of fit() when L-BFGS-B stops at max_iter before converging; increase max_iter or tol in that case.

tolfloat or None, default=1e-6

Stopping tolerance of L-BFGS-B on the relative reduction of the objective and on the projected gradient. None uses SciPy’s defaults, which are stricter on the objective (about 2e-9): they take about twice as many iterations for the same predictions.

continuous_children{“gaussian”, “discretized”}, default=”gaussian”

How a continuous attribute is modelled as a child. With "gaussian" it keeps its values and has a Gaussian conditional, and only its role as a parent uses the bins of n_bins and strategy. With "discretized" every continuous attribute is replaced by its bin, as a categorical attribute, in both roles: the model on discretized data of the original works, without a discretizer in a pipeline. Values beyond the training range fall in the first or the last bin.

Examples

>>> import numpy as np
>>> from sklearn.metrics import log_loss
>>> from skbn import TAN, WeightedTAN
>>> rng = np.random.RandomState(0)
>>> y = rng.randint(0, 2, size=300)
>>> x = rng.normal(size=300) + y
>>> X = np.column_stack([x, x, x, rng.normal(size=300) + y])  # x three times
>>> clf = WeightedTAN(weight_level=1).fit(X, y)
>>> clf.n_weights_  # the class prior, four attributes and the unseen key
6
>>> clf.learned_weights_.round(1)  # the copies of x count less
array([1. , 1.1, 0.3, 0.3, 1. , 1. ])
>>> tan = TAN().fit(X, y)
>>> bool(log_loss(y, clf.predict_proba(X)) < log_loss(y, tan.predict_proba(X)))
True

conditional_table(feature, as_frame=False)#

Return the conditional distribution of an attribute in the network.

The table has a row for every state of the class and of the parents of the attribute that occurs in training, with the probability of each value of the attribute, or the mean and the variance of its Gaussian. The states that do not occur have no row: there the model uses the uninformed estimate described in the class docstring.

Parameters:
featureint or str

The attribute, by its index or by its name in feature_names_in_.

as_framebool, default=False

If True, return a pandas DataFrame indexed by the class and the values of the parents, with a column per value of the attribute (or the columns mean and var).

Returns:
tableBunch or DataFrame

With as_frame=False, a dictionary-like object with:

featureint

Index of the attribute.

parentslist of int

Its parents among the attributes.

classesndarray of shape (n_states,)

Class of every row.

parent_valuesndarray of shape (n_states, n_parents)

Values of the parents in every row: their categories, or the index of the bin of a continuous parent (see cut_points_).

countndarray of shape (n_states,)

Number of training samples in the state of every row.

feature_valuesndarray of shape (n_values,) or None

Values of a discrete attribute: its categories, or False and True for a Bernoulli attribute (above its threshold or not).

probandarray of shape (n_states, n_values) or None

Probability of every value in every row.

mean, varndarray of shape (n_states,) or None

Mean and variance of a Gaussian attribute in every row.

property cut_points_#

Cut-points of the continuous attributes, a list with an array per attribute that the model bins (as a parent, or as a child too with continuous_children="discretized") and None for the others. Bin b holds the values from cut_points_[i][b - 1] (included) to cut_points_[i][b], and the first and the last bin have no outer limit.

property edges_#

Arcs between attributes, as (parent, child) pairs of feature indices in the order of the children. Every attribute also has the class as a parent, which the pairs leave out.

property feature_types_#

Indices of the attributes of each type the model uses, under the keys “gaussian”, “categorical” and “bernoulli”.

property feature_weights_#

Weights of the conditional of every attribute, a list with one array per attribute, of shape (n_keys, n_classes) at weight_level 3 and 4 and (n_keys, 1) below. The rows are the combinations that the level tells apart (values of the attribute, with its parents at level 4) seen in training, a single row at level 1. An attribute the model ignores has no rows.

set_score_request(*, sample_weight: bool | None | str = '$UNCHANGED$') → WeightedTAN#

Configure whether metadata should be requested to be passed to the score method.

Note that this method is only relevant when this estimator is used as a sub-estimator within a meta-estimator and metadata routing is enabled with enable_metadata_routing=True (see sklearn.set_config()). Please check the User Guide on how the routing mechanism works.

The options for each parameter are:

  • True: metadata is requested, and passed to score if provided. The request is ignored if metadata is not provided.

  • False: metadata is not requested and the meta-estimator will not pass it to score.

  • None: metadata is not requested, and the meta-estimator will raise an error if the user provides it.

  • str: metadata should be passed to the meta-estimator with this given alias instead of the original name.

The default (sklearn.utils.metadata_routing.UNCHANGED) retains the existing request. This allows you to change the request for some parameters and not others.

Added in version 1.3.

weight_table(feature, as_frame=False)#

Return the weights of the conditional of an attribute with the combinations they belong to.

weight_level decides what a weight is shared by: the whole conditional (level 1, a single row), each value of the attribute (2 and 3), or each value with each state of the parents (4); from level 3 on there is a column per class. A Gaussian attribute has no values to tell apart, so its rows are the states of its parents alone. Only the combinations that occur in training have a weight.

Parameters:
featureint or str

The attribute, by its index or by its name in feature_names_in_.

as_framebool, default=False

If True, return a pandas DataFrame indexed by the value of the attribute and the values of its parents, with a column per class (or a single column weight).

Returns:
tableBunch or DataFrame

With as_frame=False, a dictionary-like object with:

featureint

Index of the attribute.

weightsndarray of shape (n_rows, n_classes) or (n_rows, 1)

The weights, feature_weights_[feature].

feature_valuesndarray of shape (n_rows,) or None

Value of the attribute in every row, when the level tells the values apart.

parentslist of int

Parents of the attribute, when the level tells their states apart (empty otherwise).

parent_valuesndarray of shape (n_rows, n_parents)

Values of those parents in every row.

classesndarray of shape (n_classes,) or None

Class of every column, when there is one per class.
