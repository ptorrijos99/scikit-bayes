AnJE#

class skbn.AnJE(n_join=2, n_bins=5, strategy='quantile', alpha=1.0, categorical_features=None, bernoulli_features=None, gaussian_features=None, n_jobs=None)#

Averaged n-Join Estimators (AnJE) [Generative].

The geometric mean of the n-join estimators of every subset of n of the \(a\) attributes (Zaidi et al. [1], Eq. 11):

\[P(y | x) \propto P(y) \prod_{\alpha \in \binom{A}{n}} P(x_\alpha | y)^{\frac{(n-1)!(a-n)!}{(a-1)!}}.\]

The exponent is the inverse of the number of subsets that contain a given attribute, so that every attribute enters the product with total exponent one. A1JE is Naive Bayes, and AnJE uses the same statistics as A(n-1)DE. Probabilities are m-estimates with m = alpha: \(P(y) = (\#y + m/|Y|) / (t + m)\) and \(P(x_\alpha | y) = (\#(x_\alpha, y) + m/|X_\alpha|) / (\#y + m)\).

Continuous attributes are discretized into n_bins bins (the original work uses MDL discretization, available as MDLPDiscretizer in a pipeline, or strategy='mdlp'). A discrete value never seen in training carries no information about the class: the n-joins that contain it are left out for that sample, as a missing value would be.

Parameters:
n_joinint, default=2

Size n of the attribute subsets (at least 1). With fewer attributes than n_join, the single join of all attributes is used.

n_binsint, default=5

Number of bins for continuous attributes (at least 2).

strategy{‘uniform’, ‘quantile’, ‘kmeans’, ‘mdlp’}, default=’quantile’

Binning strategy for continuous attributes. 'mdlp' places the cuts with the supervised entropy discretization of Fayyad and Irani (see MDLPDiscretizer), which chooses the number of bins of each attribute, so n_bins is not used.

alphafloat, default=1.0

Non-negative weight m of the m-estimates; with 0 the cells unseen in training have zero probability.

categorical_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the attributes to treat as discrete regardless of their dtype.

bernoulli_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the attributes to treat as discrete regardless of their dtype.

gaussian_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the attributes to treat as continuous (binned) regardless of their dtype. The attributes in none of the three parameters are typed from their training values with the rules of MixedNB, and only those typed as Gaussian are binned. Columns of labels (strings, pandas categories) are discrete and cannot be declared continuous.

n_jobsint, default=None

Number of threads used to count and evaluate the n-joins. None means 1 unless in a joblib.parallel_backend context. -1 means using all processors.

Attributes:
classes_ndarray of shape (n_classes,)

Class labels.

n_features_in_int

Number of features seen during fit.

feature_names_in_ndarray of shape (n_features_in_,)

Names of features seen during fit. Defined only when X has feature names that are all strings.

joins_ndarray of shape (n_joins, n)

Attribute subsets of the n-joins, one row per subset, with n = min(n_join, n_features_in_).

Examples

>>> import numpy as np
>>> from skbn import AnJE
>>> rng = np.random.RandomState(0)
>>> x0 = rng.randint(0, 2, size=200)
>>> x1 = rng.randint(0, 2, size=200)
>>> x2 = rng.randint(0, 3, size=200)  # noise
>>> y = x0 ^ x1  # exclusive or: no attribute is informative on its own
>>> X = np.column_stack([x0, x1, x2])
>>> clf = AnJE(n_join=2).fit(X, y)
>>> clf.score(X, y)
1.0

set_score_request(*, sample_weight: bool | None | str = '$UNCHANGED$') → AnJE#

Configure whether metadata should be requested to be passed to the score method.

Note that this method is only relevant when this estimator is used as a sub-estimator within a meta-estimator and metadata routing is enabled with enable_metadata_routing=True (see sklearn.set_config()). Please check the User Guide on how the routing mechanism works.

The options for each parameter are:

  • True: metadata is requested, and passed to score if provided. The request is ignored if metadata is not provided.

  • False: metadata is not requested and the meta-estimator will not pass it to score.

  • None: metadata is not requested, and the meta-estimator will raise an error if the user provides it.

  • str: metadata should be passed to the meta-estimator with this given alias instead of the original name.

The default (sklearn.utils.metadata_routing.UNCHANGED) retains the existing request. This allows you to change the request for some parameters and not others.

Added in version 1.3.

Parameters:
sample_weightstr, True, False, or None, default=sklearn.utils.metadata_routing.UNCHANGED

Metadata routing for sample_weight parameter in score.

selfobject

The updated object.
