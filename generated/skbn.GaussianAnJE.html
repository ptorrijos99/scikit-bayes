GaussianAnJE#

class skbn.GaussianAnJE(n_dependence=1, n_bins=5, strategy='quantile', alpha=1.0, n_jobs=None, categorical_features=None, bernoulli_features=None, gaussian_features=None, var_prior_weight=1.0, min_parent_count=1, unseen_state='laplace')#

Averaged (n+1)-Join Estimator on the factors of the SPnDEs [Generative].

The AnJE of Zaidi et al. [1] with joins of size n_dependence + 1, written as a log-linear pool of the factors of the SPnDEs of order n_dependence:

\[\log P(y | x) \propto \log P(y) + \frac{1}{|M|} \sum_{P \in M} \Big[ r \log P(x_P | y) + c \sum_{j \notin P} \log P(x_j | y, x_P) \Big],\]

with \(r = d / (n+1)\) and \(c = d / ((n+1)(d-n))\), where \(M\) holds the super-parent sets of the components that take part in the prediction. AnDE with mean="geometric" pools the same factors with exponents \(1/|M|\).

The factors are those of AnDE, so the model accepts the same mixed data: super-parents are discretized into n_bins bins and every child is scored by the conditional family of its type, Gaussian for continuous attributes, as in HAODE. The root \(P(x_P | y)\) is the Laplace-smoothed probability of the augmented state divided by its total within the class, so that every factor is a distribution conditional on the class. On discrete data the model differs from AnJE with n_join=n_dependence + 1 only in the smoothing, Laplace on the augmented states instead of m-estimates on the joins, and the two coincide as alpha tends to zero. n_dependence=0 gives Naive Bayes, which is A1JE.

Parameters:
n_dependenceint, default=1

Order n of the SPnDEs; the joins have n + 1 attributes. It must satisfy 0 <= n_dependence <= n_features; 0 gives Naive Bayes.

n_binsint, default=5

Number of bins of the continuous super-parents (at least 2).

strategy{‘uniform’, ‘quantile’, ‘kmeans’}, default=’quantile’

Binning strategy of the continuous super-parents.

alphafloat, default=1.0

Non-negative Laplace smoothing of the discrete factors and of the augmented-state prior.

n_jobsint, default=None

Number of threads used to count and evaluate the SPnDEs. None means 1 unless in a joblib.parallel_backend context. -1 means using all processors.

categorical_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the attributes to treat as categorical, passed to MixedNB, which describes how the undeclared attributes are typed.

bernoulli_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the attributes to treat as Bernoulli. See MixedNB.

gaussian_featuresarray-like of int or bool, default=None

Indices (or a boolean mask) of the attributes to treat as Gaussian. See MixedNB.

var_prior_weightfloat, default=1.0

Pseudo-observations shrinking each Gaussian child variance towards the pooled variance of the attribute (see MixedNB).

min_parent_countint, default=1

Minimum training frequency of a parent instantiation for its SPnDE to take part in the prediction of an instance. Values below 1 behave as 1.

unseen_state{“laplace”, “backoff”}, default=”laplace”

Child conditionals of an augmented state never seen in training (see AnDE).

Attributes:
classes_ndarray of shape (n_classes,)

Class labels.

class_count_ndarray of shape (n_classes,)

Number of training samples of each class.

n_features_in_int

Number of features seen during fit.

feature_names_in_ndarray of shape (n_features_in_,)

Names of features seen during fit. Defined only when X has feature names that are all strings.

ensemble_sequence of dict

The fitted SPnDEs, one per set of n_dependence super-parents (a single one for n_dependence=0). Each dict holds the "parent_indices" and "child_indices" of the component and the numbers of its parent instantiations ("n_parent_combos") and of the augmented states \(Y^*\) seen in training ("n_states"); the estimates of all the components are stored together in flat tables.

backoff_MixedNB

Naive Bayes on the original class, used for the class prior, the class-level conditionals and as the fallback when no SPnDE qualifies.

See also

GaussianALR

Discriminative weights on the factors of this model.

set_score_request(*, sample_weight: bool | None | str = '$UNCHANGED$') → GaussianAnJE#

Configure whether metadata should be requested to be passed to the score method.

Note that this method is only relevant when this estimator is used as a sub-estimator within a meta-estimator and metadata routing is enabled with enable_metadata_routing=True (see sklearn.set_config()). Please check the User Guide on how the routing mechanism works.

The options for each parameter are:

  • True: metadata is requested, and passed to score if provided. The request is ignored if metadata is not provided.

  • False: metadata is not requested and the meta-estimator will not pass it to score.

  • None: metadata is not requested, and the meta-estimator will raise an error if the user provides it.

  • str: metadata should be passed to the meta-estimator with this given alias instead of the original name.

The default (sklearn.utils.metadata_routing.UNCHANGED) retains the existing request. This allows you to change the request for some parameters and not others.

Added in version 1.3.

Parameters:
